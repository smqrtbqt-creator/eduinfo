Notions essentielles

HTTP

Protocole de communication du Web. En HTTP simple, les données circulent sans chiffrement : un observateur du réseau pourrait lire les échanges.

HTTPS

HTTP utilisé au-dessus de TLS. L'objectif est de chiffrer la communication et d'aider à vérifier l'identité du serveur via un certificat.

TLS

Protocole cryptographique qui établit une connexion chiffrée entre le navigateur et le serveur (successeur de SSL).

Certificat numérique

Document électronique présenté par le serveur. Il contient notamment le nom du site (ou localhost), une clé publique et des informations sur l'émetteur.

Autorité de certification (CA)

Organisme de confiance qui signe des certificats. Les navigateurs connaissent une liste d'autorités reconnues. Un certificat signé par une CA inconnue déclenche un avertissement.

Certificat expiré

Un certificat n'est valable que pendant une période donnée. S'il est expiré, le navigateur refuse de faire confiance à la connexion.

Certificat auto-signé

Certificat créé et signé par le serveur lui-même, sans autorité de certification publique. C'est le cas de ce site de TP : Firefox affiche un avertissement volontaire.

Certificat correspondant à un autre domaine

Si vous visitez exemple.fr mais que le certificat est délivré pour autre-site.fr, le navigateur signale une incohérence de nom (erreur de correspondance).

Sur ce site de démonstration

Le serveur utilise un certificat auto-signé de développement. Il n'est pas reconnu par Firefox. C'est voulu : l'élève doit pouvoir constater l'avertissement, examiner le certificat, puis décider de poursuivre uniquement dans le cadre du TP.

Ne jamais accepter un tel avertissement sur un véritable site demandant des données personnelles, sauf instruction claire d'un contexte pédagogique contrôlé.
